# Proyek Akuisisi dan Manajemen Data

## 1. Deskripsi Proyek
Proyek ini dibuat untuk memenuhi tugas praktikum mata kuliah Akuisisi dan Manajemen Data. Proyek ini membahas proses pengelolaan data menggunakan Python dan library Pandas.

## 2. Tujuan
Tujuan proyek ini adalah memahami tahapan Data Science Lifecycle, mulai dari pengumpulan data hingga penyampaian hasil analisis.

## 3. Tahapan Data Science Lifecycle
Proyek ini mencakup enam tahapan utama:

1. **Acquisition:** Mengumpulkan data dari sumber yang tersedia.
2. **Storage:** Menyimpan data agar dapat diakses dan dikelola.
3. **Cleaning:** Membersihkan data dari kesalahan, duplikasi, dan nilai kosong.
4. **Transformation:** Mengubah data ke format yang sesuai untuk analisis.
5. **Analysis:** Menganalisis data untuk memperoleh informasi.
6. **Delivery:** Menyampaikan hasil analisis dalam bentuk tabel, laporan, atau visualisasi.

## 4. Tools yang Digunakan
- Python
- Google Colab
- Pandas
- GitHub

5. Environment
Versi Python dan Pandas diverifikasi melalui kode Python yang dijalankan di Google Colab.

##6. Cara Menjalankan
1. Buka notebook menggunakan Google Colab.
2. Jalankan setiap sel kode secara berurutan.
3. Periksa hasil pemetaan Data Science Lifecycle.
4. Pastikan file `lifecycle.csv` berhasil dibuat.
